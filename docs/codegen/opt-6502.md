# Optymalizacje codegen: MOS 6502 (+65C02 / NES / 6510)

Stan na main po planach 40–45. Plan 43 (DJNZ Z80) i plan 45 (łańcuchy `jmp`) są zamknięte; ABI v2 jest dostępne tylko jako pilot na `nes`.
Warianty `65c02`/`nes`/`6510` to flagi `Mos6502Target`, jeden selektor.

| Ficzer | Status | Dowód / uwagi |
| --- | --- | --- |
| Rejestry komórek (alokator) | brak | `CellRegisters`/`CellPairs` puste; brak mapy rejestrów. Parametry i wyniki w pamięci (`cc_argN`/`cc_ret`) |
| ParamAlias (liście → `cc_argN`) | zrobione | Wspólny przebieg (little-endian); usuwa prologową kopię parametru |
| Wynik w rejestrze | brak | `ReturnsInResultReg` fałsz; wynik wraca przez `cc_ret` |
| Słowa przez pary (`TryMoveWord`/`TryAddWord`/`TryShlWord1`) | brak | Brak par rejestrowych; arytmetyka słów łańcuchem bajtów przez A |
| Porównania ze znakiem (forma zerowa) | zrobione | `TryBranchZeroSigned`; fold biasu `xor 128` wprost w A (`XorPreservesCarry`) |
| Porównania ze znakiem (forma ze stałą) | brak | Bez `TryBranchSignedConst`; stałe idą trampoliną `JumpIfSigned` (S^V) |
| Peephole `Tidy` | brak | Brak reguł tekstowych (redundant/dead/xor-a istnieją tylko na Z80/8080) |
| Relaksacja skoków | zrobione | `BranchRelaxer.Apply`; brak krótkich skoków do relaksacji |
| Tail call | zrobione | `jmp` + `jmp __icall` (`SupportsTailCall`); `TailCall6502Tests`; martwa stopka pomijana przy pustej ramce |
| Ramki (`Saved`, push/pop) | częściowe | `PushA`/`PopA` tak; brak `TryPushWord`/`TryPopWord` i ścieżki `keepResult` |
| Wskaźniki i indeksowanie | zrobione | `PtrSetup`/`PtrLoad`/`PtrStore` przez `__p` na stronie zerowej + `LDY`; `IndexFusion` (`SupportsIndexed`) |
| Strona zerowa komórek | zrobione | Prefiks `z:` (`AddZeroPage`); `cc_argN`/`cc_ret`/`cc_t*` na ZP |
| Kopiowanie bloków (LDIR) | brak | Brak rozkazu blokowego; matcher `TryCopyLoop` zwraca `false` |
| Strength reduction | częściowe | Mnożenie przez stałą w `Legalizer` tak; hak `Add(x,x)` tylko dla CPU z `TryShlWord1` (tu nie) |
| Switch `uchar` → 1 B | zrobione | `LowerSwitch` zwęża porównania; `SwitchNarrowTests` sprawdza też case poza zakresem bajtu |
| DJNZ / RST | brak | Brak rozkazów; nie dotyczy |
| ABI v2 (rejestry) | częściowe | Pilot tylko na `nes`; pozostałe warianty 6502 nadal ABI v1 |

## Braki / next

- Rejestry komórek (np. liczniki/parametry w X/Y) — brak aktywnego planu; najpierw potrzebny pomiar potencjalnego zysku i testów liveness.
- Forma ze stałą dla porównań ze znakiem (odpowiednik `TryBranchSignedConst` bez flagi V) — do policzenia, czy się zwraca.
- `Tidy` dla 6502 (martwe `tax`/`txa`, `lda`→`tax` forwarding) — osobny zestaw reguł, ostrożnie z flagami.

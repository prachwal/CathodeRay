# Optymalizacje codegen: Intel 8080

Stan na gałęzi `opt/z80-codegen` (main + plan 40, batche 1–3). Model: A + pary BC/DE/HL, wynik w HL.
ABI v2 nie dotyczy (pilot `nes` tylko na `opt/abi-v2`).

| Ficzer | Status | Dowód / uwagi |
| --- | --- | --- |
| Rejestry komórek (alokator) | zrobione | `CellRegisters`/`CellPairs` + `RegisterAllocator.Tune`; parametry w puli (plan 40, item 9-część); `SavedAround` push/pop wokół wołań |
| ParamAlias (liście → `cc_argN`) | zrobione | Little-endian; globalne pomijanie go na Z80/8080 odrzucone (regresja mean 1.15→1.35) |
| Wynik w rejestrze | zrobione | `ReturnsInResultReg`; `TryMoveTo/FromResultReg`, `ResultByteFrom/ToA`; zamiana do DE przez `xchg` |
| Kopie słów (`TryMoveWord`) | zrobione | Przez HL (`lhld`/`shld`), do par `mov c,l; mov b,h` |
| Shift słowa (`TryShlWord1`) | zrobione | `dad h`; flaga `FreshAddInHL`; hak `Add(x,x)` w selektorze (`StrengthReductionTests`) |
| Arytmetyka słów (`TryAddWord`) | brak | Brak implementacji; dodawanie słów łańcuchem / helperami |
| Porównania ze znakiem (forma zerowa) | zrobione | `TryBranchZeroSigned` |
| Porównania ze znakiem (forma ze stałą) | brak | Świadomie: fold biasu wycofany po 41 padach matrycy (każdy ALU 8080 gasi borrow); listing bit-identyczny, trampolina zostaje |
| Peephole `Tidy` | zrobione | Redundant/dead `mov` BC/DE↔HL; `mvi a,0`→`xra a` po labelce/bezwarunkowym `call` (`AsmTidyTests` ±) |
| Relaksacja skoków | zrobione | `DropJumpToNext` (brak krótkich skoków do relaksacji) |
| Tail call | zrobione | `jmp` + `pchl`; `TailCallTests`; martwa stopka pomijana przy pustej ramce |
| Ramki (`Saved`, push/pop) | zrobione | `TryPushWord` (`lhld`+`push h`); `TryPopWord` (`pop h`+`shld`, przy wyniku `xchg` wokół) |
| Wskaźniki | zrobione | `PtrSetup`/`PtrLoad`/`PtrStore` przez HL; bez `IndexFusion` |
| Kopiowanie bloków (LDIR) | brak | Brak rozkazu; matcher zwraca `false` (celowo) |
| Strength reduction | zrobione | Hak `Add(x,x)` (`dad h`) + mnożenie przez stałą w `Legalizer` |
| Switch `uchar` → 1 B | zrobione | Zwężenie w `LowerSwitch` (wspólne) |
| DJNZ / RST | brak | Brak rozkazów; nie dotyczy |
| ABI v2 (rejestry) | brak | Nie dotyczy |

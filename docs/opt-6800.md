# Optymalizacje codegen: Motorola 6800

Stan na gałęzi `opt/z80-codegen` (main + plan 40, batche 1–3). Big-endian: komórka 2-bajtowa trzyma starszy bajt pod symbolem.
ABI v2 nie dotyczy (pilot `nes` tylko na `opt/abi-v2`).

| Ficzer | Status | Dowód / uwagi |
| --- | --- | --- |
| Rejestry komórek (alokator) | brak | `CellRegisters`/`CellPairs` puste; brak mapy rejestrów |
| ParamAlias (liście → `cc_argN`) | brak | Przebieg tylko little-endian; 6800 jest big-endian, więc aliasowanie wyłączone |
| Wynik w rejestrze | brak | `ReturnsInResultReg` fałsz; wynik wraca przez `cc_ret` |
| Kopie słów (`TryMoveWord`) | zrobione | Przenoszenie słów parą; bez `TryAddWord`/`TryShlWord1` |
| Arytmetyka słów w rejestrach | brak | Brak odpowiednika `add hl,hl`; łańcuch bajtów przez A |
| Porównania ze znakiem (forma zerowa) | zrobione | `TryBranchZeroSigned`; fold biasu `eora 128` wprost w A (`XorPreservesCarry`, model potwierdza brak C) |
| Porównania ze znakiem (forma ze stałą) | brak | Bez `TryBranchSignedConst`; stałe idą trampoliną |
| Peephole `Tidy` | brak | Brak reguł tekstowych |
| Relaksacja skoków | zrobione | `BranchRelaxer.Apply` |
| Tail call | brak | Brak `SupportsTailCall`; wołania zawsze `call`+`ret` |
| Ramki (`Saved`, push/pop) | częściowe | `PushA`/`PopA` tak; brak `TryPushWord`/`TryPopWord` i ścieżki `keepResult` |
| Wskaźniki | zrobione | `PtrSetup`/`PtrLoad`/`PtrStore` przez X (`LDAA n,X`); bez `IndexFusion` |
| Strona bezpośrednia komórek | częściowe | Prefiks `z:` tylko w formach z trybem bezpośrednim (`INC/DEC/TST` zostają przy adresie rozszerzonym) |
| Kopiowanie bloków (LDIR) | brak | Brak rozkazu blokowego |
| Strength reduction | częściowe | Mnożenie przez stałą w `Legalizer` tak; hak `Add(x,x)` tylko dla CPU z `TryShlWord1` (tu nie) |
| Switch `uchar` → 1 B | zrobione | Zwężenie w `LowerSwitch` (wspólne) |
| DJNZ / RST | brak | Brak rozkazów; nie dotyczy |
| ABI v2 (rejestry) | brak | Nie dotyczy |
